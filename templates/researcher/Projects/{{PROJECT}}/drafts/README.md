# drafts

Paper drafts targeting venues for {{PROJECT}}.

Sub-structure:
- `<venue>-<year>/` — one folder per target venue
  - `main.md` or `main.tex` — the draft
  - `notes.md` — author notes, things to fix
  - `reviews/` — once submitted, store reviews here

Cross-project paper pipeline view lives in `Projects/Papers/Papers.md`.
